# Demo Apps

Customer-facing demonstrations for dexterous robotic hands.

## Demos

| Demo | Purpose |
|---|---|
| `01-grasp-showcase` | Visual grasp sequence demo for small objects. |
| `02-teleoperation-glove` | Glove-to-hand teleoperation scaffold. |
| `03-rl-policy-inference` | Placeholder for pre-trained policy inference. |
| `04-mujoco-sim` | Simulation entrypoint and asset expectations. |
| `05-ros2-moveit` | MoveIt 2 integration notes and launch scaffold. |

Each demo is intentionally small, reproducible, and suitable for workshop or prospect demo use.
